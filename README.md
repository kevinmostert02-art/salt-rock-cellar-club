# Salt Rock Wines – World-Class Luxury Website



Build a world-class luxury website for **Salt Rock Wines**. The objective is not simply to display products, but to increase direct wine sales, encourage repeat purchases, and position Salt Rock Wines as one of South Africa's most premium wine brands.



---



# Existing Website Content (VERY IMPORTANT)



Use the existing **Salt Rock Wines** website as the primary source of truth.



Do **not** invent wines, tasting notes, vintages, awards, history, bottle images, or brand information.



Instead:



* Extract all existing wine information from the current Salt Rock Wines website.

* Use the existing bottle images in the highest quality available.

* Reuse product names exactly as they appear.

* Import wine descriptions and tasting notes.

* Import food pairing information where available.

* Import vintage information where available.

* Import the winery story and history.

* Import the existing logo and branding.

* Import awards and recognitions where available.

* Preserve the authentic Salt Rock Wines identity.



If downloadable wine specification sheets or PDFs exist, automatically use them to enrich each wine page.



Only create placeholder content where no information exists, and clearly mark placeholders.



The objective is **not to redesign the Salt Rock Wines brand**, but to elevate it into a world-class digital experience.
